# Data layout

This repository does not redistribute third-party source databases or large feature
caches. See `docs/DATA.md` for provenance, licensing, preprocessing, pocket
construction, and the prepared-batch schema.

Small, redistributable examples belong in `data/examples/`; immutable paper split
indices belong in `data/splits/`. Generated data under `data/raw/`, `data/processed/`,
and `data/features/` are ignored by Git.
