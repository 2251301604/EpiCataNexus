# Reproducing the manuscript analyses

## Reproduction levels

The release separates three levels so that a successful check is not confused with a
full paper reproduction:

1. **Lightweight verification:** configuration, metrics, original-figure checksums, and
   neural-module tests (`pytest`, `scripts/smoke_test.py`).
2. **Legacy checkpoint compatibility:** strict loading and inference with the externally
   released pooled-feature `kcat` and `Km` neural checkpoints.
3. **Canonical reconstruction:** licensed source data, structures, fpocket, all
   pretrained encoders, residue-level feature generation, training, and engineering
   analyses using `epicatanexus.models.EpiCataNexus`.

Only level 1 is self-contained in the source repository. Level 2 requires the external
checkpoint files and pooled feature inputs; level 3 requires the artifacts listed in
`docs/RELEASE_CHECKLIST.md`.

## Legacy pooled checkpoint validation

```bash
python scripts/verify_legacy_checkpoint.py /path/to/kcat_or_km_checkpoint.pkl
```

This verifies exact parameter compatibility. It does not regenerate a paper benchmark
without the corresponding fixed evaluation inputs.

## Canonical kcat and Km benchmark interface

```bash
python scripts/evaluate.py \
  --checkpoint checkpoints/epicatanexus_kcat.pt \
  --batches data/features/kcat_test_batches.pt \
  --output-dir outputs/kcat_test

python scripts/evaluate.py \
  --checkpoint checkpoints/epicatanexus_km.pt \
  --batches data/features/km_test_batches.pt \
  --output-dir outputs/km_test
```

Expected rounded metrics are recorded in `results/paper_metrics.csv`.
Canonical residue-level checkpoints are not included in the initial pooled-feature
weight release.
